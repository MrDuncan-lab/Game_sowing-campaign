# Посевная

Карточная игра про ферму: посадка культур на поле, погода, уход за грядками, селекция, рынок и заказы. Интерфейс рассчитан на телефон и компьютер.

В репозитории находится сборка от 29 октября 2026 года: одна игра «свой дом + вылазки» (прогрессия v3), сюжетная линия с Пряхиным, испытания года, обучение v4 и правки по аудитам ([24.10](docs/AUDIT-2026-10-24-STATUS.md), [QA 28.10](docs/QA-2026-10-28-STATUS.md)).

## Испытания года

С третьего года на ферме одно объявленное испытание в год — чёрный заморозок, великая саранча или великая сушь — и новая постройка «Костры». Правила и замеры: [docs/TRIALS-2026-10-28.md](docs/TRIALS-2026-10-28.md). Посмотреть: Режим проверки → Ситуации → «Испытание: …».

## Запустить игру

Скачайте [posevnaya-preview.html](https://github.com/MrDuncan-lab/Game_sowing-campaign/raw/refs/heads/main/posevnaya-preview.html) и откройте его в браузере. Игра собрана в один HTML-файл (около 11,5 МБ: портреты и шрифты лежат внутри); установка и сервер для запуска не требуются. Интерфейс рассчитан на телефон в портрете (от 320 px), на компьютере тоже работает.

[Финальный ZIP с HTML и исходниками](https://github.com/MrDuncan-lab/Game_sowing-campaign/releases/latest)

Сохранения хранятся в браузере. Режим проверки использует отдельную тестовую ферму.

## Проверить события

Откройте **Меню → Режим проверки → Ситуации → «Ненастья наперегонки»** и завершите неделю. В этом сценарии последовательно встречаются мороз, засуха, жуки, саранча, дети и вороны.

Альтернативный вход в режим проверки: добавьте `#test` к адресу открытого HTML-файла.

## Разработка

Нужны Node.js и npm.

```sh
npm ci
npm run dev
```

Проверки и сборка:

```sh
npm test
npx tsc --noEmit
npm run build
```

Результат сборки — `dist/index.html`, самостоятельный HTML-файл.

## Структура

- `src/engine/` — правила игры и данные.
- `src/ui/` — интерфейс и управление анимациями.
- `src/art/`, `src/assets/` — рисунки, портреты и шрифты.
- `tests/` — автоматические проверки.
- `tools/` — вспомогательные сценарии.
- `posevnaya-preview.html` — готовая игра.
- `verification/` — результаты проверок финальной сборки.
- [Статус правок аудита 24.10](docs/AUDIT-2026-10-24-STATUS.md), [список исправлений 21.10](docs/FIXES-2026-10-21-RU.txt).

Для сборки 24.10 прошли 171 автоматический тест и браузерные проверки в Chromium (подробности — в статусе аудита). Баланс не менялся, кроме согласованного правила улья: он опыляет со следующей недели после установки или переноса.

Правки по матрице QA от 28 октября (только код движка и сохранений, интерфейс не менялся) — [статус по сценариям](docs/QA-2026-10-28-STATUS.md); после них проходят 253 автоматических теста.

Новое обучение для новичков (учебная ферма Палыча, глава I за четыре недели, закрытые разделы под замком) — [docs/ONBOARDING-v4.md](docs/ONBOARDING-v4.md).

**Состояние на 29.10:** `npm test` — 365 тестов, все проходят (5 из них сравнивают со старыми сохранениями и в неглубоком клоне без коммита `3552a1e` пропускаются). Сохранения — формат v5; сохранения более ранних форматов не переносятся. Портреты — рисованные файлы в трёх стилях; план их выравнивания и промпты — [docs/ART_PROMPTS-v5.md](docs/ART_PROMPTS-v5.md).

Прогрессия v3 (ветка `progression-v3`, [docs/PROGRESSION-v3.md](docs/PROGRESSION-v3.md)): стройки берут деньги, материалы (брёвна, кирпич, стекло) и время, зимой идут вдвое медленнее, им можно помогать своими рабочими днями; дом растёт до 7 уровней, работники нанимаются на свободную кровать; ярмарка сезона продаёт технику, дрон, метеоприборы, материалы и работников, а сосед Пряхин перекупает лоты; на заросших грядках растут деревья на брёвна, разлив реки выносит камни; на Кубани и Алтае вместо дома — лагерь. Прогоны ботов: `npx tsx tools/progression-sim.ts`.
