# Посевная

Карточная игра про ферму: посадка культур на поле, погода, уход за грядками, селекция, рынок и заказы. Интерфейс рассчитан на телефон и компьютер.

В репозитории находится сборка от 24 октября 2026 года: исправления по единому аудиту интерфейса, механики и анимаций ([статус по пунктам](docs/AUDIT-2026-10-24-STATUS.md)).

## Запустить игру

Скачайте [posevnaya-preview.html](https://github.com/MrDuncan-lab/Game_sowing-campaign/raw/refs/heads/main/posevnaya-preview.html) и откройте его в браузере. Игра собрана в один HTML-файл; установка и сервер для запуска не требуются.

[Финальный ZIP с HTML и исходниками](https://github.com/MrDuncan-lab/Game_sowing-campaign/releases/latest)

Сохранения хранятся в браузере. Режим проверки использует отдельную тестовую ферму.

## Проверить события

Откройте **Меню → Режим проверки → Ситуации → «Ненастья наперегонки»** и завершите неделю. В этом сценарии последовательно встречаются мороз, засуха, жуки, саранча, дети и вороны.

Альтернативный вход в режим проверки: добавьте `#test` к адресу открытого HTML-файла.

## Разработка

Нужны Node.js и npm.

```sh
npm ci
npm run dev
```

Проверки и сборка:

```sh
npm test
npx tsc --noEmit
npm run build
```

Результат сборки — `dist/index.html`, самостоятельный HTML-файл.

## Структура

- `src/engine/` — правила игры и данные.
- `src/ui/` — интерфейс и управление анимациями.
- `src/art/`, `src/assets/` — рисунки, портреты и шрифты.
- `tests/` — автоматические проверки.
- `tools/` — вспомогательные сценарии.
- `posevnaya-preview.html` — готовая игра.
- `verification/` — результаты проверок финальной сборки.
