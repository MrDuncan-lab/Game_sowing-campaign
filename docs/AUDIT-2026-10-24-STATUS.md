# Аудит 24.10.2026 — статус правок

Источник требований: единый реестр PSV-001…PSV-039 (`posevnaya_unified_audit_fixlist_2026-10-24.zip`).
Базовый коммит аудита: `3552a1e`. Правки — ветка `audit-fixes-2026-10-24`, четыре коммита по фазам.

Проверка: `npx tsc --noEmit`, `npm test` (171 тест, из них 11 новых в `tests/audit-fixes.test.ts`),
`npm run build`, прогон в Chromium (Playwright) на 1363×936, 740×360, 390×844, 320×568 и с уменьшением движения.
Firefox, Safari и реальные телефоны не проверялись.

Решения, принятые с автором игры:
- улей опыляет со следующей недели после установки или переноса — как теплица (PSV-021);
- капельный полив: правится текст, механика не меняется (PSV-023);
- зелёные кнопки: тёмная надпись на прежнем зелёном (PSV-026);
- из крупных перестроек сейчас сделана только панель покупки в Лавке (PSV-003); веер карт, десктоп-раскладка,
  единая художественная система и шапки Дома/Амбара отложены для обсуждения.
